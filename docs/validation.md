| 设备 | 结果 |
| --- | --- |
| G502 X PLUS，046D:C547 | 原生 C++ 读取百分比成功 |

验证时 G HUB、SteelSeries GG 保持运行。真实充电切换、长时间运行、系统恢复和多显示器不同 DPI 尚需扩展覆盖。鼠标“静置”依活动推断，不是固件确认的睡眠标志。

K99 V3 的实机灯光在静置后熄灭，按键后亮起，监听期间没有看到相应的无线链路通知。无线通知解析、缓存和恢复使用 SDK 定义的报文做回归测试。

## 自动检查

CTest 包含 protocol_parsers、ui_regression 和 autostart_regression。

[首次 GitHub Actions 构建](https://github.com/Axiomerator/peripheral-battery-checker/actions/runs/41211104878)已在 windows-2022 运行器上完成独立构建、两项测试与便携打包，全部通过。云端验证使用模拟设备，不替代下面的本机硬件证据。

- 协议：前缀、槽位、长度、越界值、Windows 前导 00、离线、充电。K99 V3 回归覆盖两种实测充电状态、校验错误、截断、越界和设备信息回包。
- 缓存：73% 后出现突变 15% + 充电时保留原值；静置不覆盖旧值；旧缓存允许合法放电变化。
- 界面：十二台模拟设备的排序、保存恢复、隐藏筛选、托盘前三台、三个列表滚动、缩放、边缘自动滚动与取消。
- 固定通用设置：列表首尾坐标及点击命中不变；640×420 小窗口中刷新间隔、自启和列表无重叠。
- 绘制：60 个按钮按下 / 切页缓冲画面全部不透明，未见白色填充。100%、125%、150%、200% DPI 下验证速览和主窗口能容纳三位数电量。
- K99 V3 链路状态：模拟通信中断和恢复通知，核对未连接状态、保留电量、暂停查询和恢复补读。
- 关闭：X 和系统窗口关闭隐藏主窗口，保留托盘宿主。
- 界面测试与日常常驻实例隔离，不查询真实 HID。

检查通过，命令和产物位置见 [开发说明](development.md)。缓冲画面与窗口截图检查不等同于真实桌面连续录屏。

旧版 Run 自启曾通过创建、读回、撤销检查，但用户随后反馈重启未启动；2026-11-01 核查时，真实用户的 Run 与启动文件夹均无本程序注册项，旧验证未覆盖登录链路。

0.1.1 改用当前用户启动文件夹中的原生快捷方式，增加目标 / 参数 / 工作目录核验、系统状态刷新、错误反馈和旧项清理。隔离回归覆盖中文与带空格路径、错误目标 / 参数、Windows 禁用与重新开启、重复移除及写入失败。本机实际注册后，Win32_StartupCommand 已枚举到 Peripheral Battery；启动文件夹快捷方式可正常启动 --tray 进程。关闭及重复关闭后快捷方式和枚举项均移除，旧 Run 项不存在；重新开启及正常启动时的旧 Run 项迁移通过，个人 settings.ini 哈希不变。测试结束保留自启开启。

真实登录结果需要注销后重新登录确认，步骤见 [自启说明](autostart.md)。单实例启动已验证。

## 资源采样

本机一次采样结果，未强制裁剪工作集，每种状态采样 10 秒：

| 场景 | 总工作集 MiB | 专用工作集 MiB | 专用提交 MiB | 10 秒 CPU 时间 |
| --- | ---: | ---: | ---: | ---: |
| 托盘常驻 | 13.602 | 1.516 | 2.051 | 0.000 秒 |
| 主窗口打开 | 19.387 | 2.328 | 3.074 | 0.000 秒 |

总工作集包含 Windows 共享库，随设备状态、字体缓存和交互变化。采样早于固定通用设置的布局调整；资源数据不是上限承诺。EXE 约 0.76 MiB，使用静态 C++ 运行库。

绘图线程没有文本输入框，在创建窗口前关闭自身 IME 关联，避免加载不需要的输入法组件。API 依据：[Microsoft ImmDisableIME](https://learn.microsoft.com/en-us/windows/win32/api/imm/nf-imm-immdisableime)。

原始设备探测、个人配置和本地测试截图保留在维护者机器，不纳入公共仓库或便携包。
