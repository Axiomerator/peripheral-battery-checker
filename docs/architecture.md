# 实现

C++20 + Win32 + GDI+。静态运行库，无浏览器内核、Qt、.NET、Python 运行时依赖。
系统消息循环和原生托盘；软件绘图、临时双缓冲。隐藏时不持续绘制。

一个后台线程通过 condition_variable 等待。默认每 60 秒查询；静置设备跳过。设备活动、连接变化和系统恢复合并处理。HID 超时后 CancelIoEx，并等待取消完成再释放 OVERLAPPED。

登记与显示独立，设备保存各自最后有效电量及状态。G502 优先接收器，避免充电时有线和无线重复。

## 界面与顺序

绘图线程没有文本输入框，创建窗口前关闭该线程的输入法关联。每个窗口只有一个绘图画布；按钮、卡片、滚动条在同一块不透明缓冲位图中绘制后一次提交。移除原生 BUTTON 子窗口，避免其默认背景擦除与父窗口绘制分帧产生白块。按钮保留鼠标按下 / 悬停 / 焦点状态及 Tab、Space、Enter 操作。

固定标题和底部操作；设置页另为刷新间隔、开机自启预留底部固定区域，只让设备列表按视口裁剪并滚动。固定设置按钮不应用滚动偏移，设备拖放与滚动条范围止于固定区域上方。小尺寸设置窗口压缩页头以保持通用设置完整可见。中间列表使用逻辑坐标与每页滚动偏移。命中检测使用相同坐标变换，滚动后的按钮不会覆盖固定区域。支持滚轮、轨道 / 滑块拖动、键盘翻页、拖拽边缘自动滚动。窗口按当前 DPI 布局并允许改变尺寸，不再按设备数量放大窗口或缩小整页。

拖拽使用设备 key 标识，松开时调整全局设备顺序并保存；拖动期间只显示插入位置。排序不触发 HID 查询。概览 / 速览过滤后保持全局顺序，托盘从中取前三台；设置同时包含隐藏或未登记的设备。新发现的设备追加到已有明确排序之后。

INI 的每个设备段保存 order；旧配置缺少 order 时继续采用原来的型号顺序。配置先写临时文件再替换，只在设置 / 顺序变化和新设备加入时保存。不持续写日志。开机自启由当前用户 Run 项控制，无需提权，不修改设备配置。

内存同时报告专用工作集、专用提交与含共享系统库的总工作集，不强制裁剪工作集。
